## 实际浏览器操作

浏览器：本机预览 http://127.0.0.1:4325/index.html。桌面 1280×720，响应式手机视口 390×844。

| 情况 | 实际结果 |
| --- | --- |
| 首次 / 未参与 | 新进度没有食材、报纸或交付；直接夜游的周姐显示备用安排，不出现交菜确认按钮。 |
| 选择莲藕 | 青菜、莲藕称重后接受预留；周姐核对这两样，并明确留作明早，今晚的汤是中午煨好的。 |
| 没有莲藕 | 青菜、白萝卜可正常预留并交接；周姐说明配菜已收，莲藕另备。 |
| 不接受帮忙 | 选择“自己带走”；夜间不会称作替陈姨送过菜，也不会出现交付按钮。 |
| 完成交付 / 回访 | 交菜后重复打开只看见已接收回应，不能再次交菜。陈姨在纳凉处提醒取空篮。 |
| 取回与刷新 | 主动接过空篮；刷新并回访，陈姨说篮子已经拿回，不再出现接篮按钮。 |
| 手机完整主线 | 手机完成称重、接受、夜间交接、找陈姨接回空篮；按钮、文字均可见可用。 |
| 跳过白天看电影 | 可直接拉幕、转手轮看完整四段故事；基础叙事由街坊自身经历成立。 |
| 小报与电影回应 | 展开早报后再入电影，开场变为“早报预告过这只篮子”。可暂停在一页阅读。 |
| 物件发现与人物 | 杂货柜认出杯底△后，回过早铺吴姐提到这次发现，并保留已选少辣口味。 |
| 吴姐记口味 | 选择少辣、刷新，再交谈显示“少点辣，便条压在碗底”，未把未制作的新口味说成已做好。 |
| 字幕节目 | 李伯节目自动走完六句后解锁新对白。手机可阅读、暂停或逐句翻看。 |
| 切台 / 配乐恢复 | 14% 基础音量播放字幕时降到约 3.92%；更改基础音量为 22% 后，调离频道及离场恢复到 22%，不强行改回默认值。 |
| 快速切场 | 吴姐入口刚点击便切到夜间，旧对白没有在新全景弹出；离场取消字幕、动画与临时界面。 |
| 未取报的轮渡 | 小报读完放回、没选过菜，只验票过江；收尾只写验过的纸票，没有菜篮或随身报纸。 |
| 个人明信片 | 实际生成 PNG，记录少辣、读报后放回、验票、完成节目、发现旧单 / 修补等事实；没有虚构送菜。测试输出使用通用测试短句，之后恢复原留言。 |
| 重逛 | “这一天 → 重新逛这一天”恢复晨起、清除故事进度。旧明信片文字及本地配乐独立保存。 |
| 手机纸笺与对照 | 纸笺随场景移动，并避开底部导览；旧单、修补对照可打开、阅读、关闭，小报有独立阅读区。 |

修复了测试中发现的手机纸笺遮挡、纸笺被旧门热区穿透、转场旧动作保护，以及改口味后误沿用“已做好”状态等问题。

## 真实限制

- 广播是完整字幕播放版，没有人声配音，也没有拿无关音效冒充节目。
- 2009 / 2012 等年份是原创人物故事时间；对照不是历史实拍。真实旧照和获授权口述可后续替换。
- 手机为响应式浏览器视口检查，未作实体触屏或扬声器听感评测。
- 实测入口为本地 HTTP，未实测 file://。
