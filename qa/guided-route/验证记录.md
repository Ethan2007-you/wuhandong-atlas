本轮在本机 HTTP 预览中实际操作。PC 1280×720、手机视口 390×844；不宣称实体设备测试。

## 实际走通

开场出发 → 选少辣并看做面完成 → 菜场选青菜、莲藕并称平秤杆 → 答应代留 → 展开报纸、放回 → 江滩点两次蒲扇 → 码头验票 → 坐完轮渡 → 切入入夜汤铺 → 核对交菜 → 点炭火 → 斟满汽水 → 拉幕、转手轮、对焦并看完四段电影 → 向陈姨接过空篮 → 放线、提线 → 路线收尾。

十二站均有实际操作后的完成回馈，切场不算完成。

## 分支与手机

- 手机实际选择青菜、白萝卜，称重后选择自己带走。
- 主动跳过几站，汤铺指引说明“不代送菜，听砂锅”，可正常继续，不产生交菜记录。
- 陈姨对话确认自己带菜、周姐另备，不出现领取空篮按钮。
- 跳过与完成分开；刷新后路线位置保持。
- 界面重置同时清除路线与菜篮进度，回到晨起；重新加载出现开场。
- 修复手机品牌、声音按钮换行与时段切换遮挡路签的问题。当前一步、对应互动、底部导航可读可点。
- 开场可关闭、随时重开；自由逛会隐藏路签并保留继续位置。
