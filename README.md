# 武汉东 · 街坊记 / 跟着逛完这一天

十二个插画场景、一条清楚的游逛路线。开场先告诉你：替陈姨留一篮明早的菜，坐一班轮渡，入夜交给周姐，找陈姨取回空篮，最后到江边收竿。

## 运行

双击 `打开本地预览.cmd`，或执行 `node server.mjs` 后打开显示的本机地址。无构建步骤、无项目依赖，脚本、素材和配乐全部在本地。直接 file:// 方式未在本轮实测。

## 从这里开始

开场点击“从过早铺出发”。小路签只显示当前一步、操作方式和下一站；点击“做这一步”会直接打开对应互动。完成后点击“继续”。

晨起：过早铺选口味看做面 → 菜摊挑两样并称重、决定是否代留 → 报摊展开电影预告 → 江滩摇扇 → 码头验票 → 轮渡过江。

入夜：汤铺核对交菜 → 烧烤炉点亮炭火 → 杂货铺斟汽水 → 院坝拉幕、转手轮、对焦看短片 → 纳凉处找陈姨取空篮 → 江边放线、提线，结束一天。

不帮忙时汤铺改为听砂锅，陈姨处改为打招呼。没有交菜就不会拿回空篮。可以明确跳过某步，也可以关闭开场自由逛，顶部“跟着逛 / 这条路线”随时继续。跳过与完成分开记录。

## 本次精简

已移除全部明信片入口、编辑、存字、Canvas 导出与约 9 MB 专用图片脚本。历史浏览器留言不会被网页读取或擅自清除。

找杯子和年代对照已从主要点位撤下。电影改为《从街口到江边》，回应今天实际交菜情况，散场明确去找陈姨。路线没有积分、倒计时和通关门槛。

## 轮渡镜头

航行时船身随波轻微升降、侧倾，栏杆与岸景分层运动；起航和靠岸逐渐收稳。暂停会同时停住船身与岸景，离场清理航行动画。系统启用减少动态效果时不做颠簸。

## 状态与主要文件

- `route.js` / `route.css`：开场路书、当前路签、十二步推进、完成与跳过状态。
- `app.js`：镜头、时段与场景切换、对应互动入口。
- `periods.js`：实际生效的十二场景和热点。
- `journeys.js`：拖动、摇扇、验票、过江、电影、汽水和钓鱼。
- `content.js` / `story-state.js` / `story-ui.js`：街坊对白、真实选择与菜篮事件。
- `qa/guided-route/`：本轮验证。`qa/story-day/` 为历史记录，不代表当前界面。

路线保存在 `wuhandong-guided-day`，人物和菜篮状态保存在 `wuhandong-story-day`。刷新保留；顶部“这一天 → 重新逛这一天”同时重置两者，保留配乐。损坏或不可用的本地存储会安全回退。

广播为三段原创字幕节目，尚无人声录音。人物与小报均为原创虚构，不冒充武汉历史资料。声音须经用户交互启动，可静音。
