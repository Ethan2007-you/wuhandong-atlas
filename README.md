# 武汉东 · 街坊记 / 有记忆的一天

在已有晨夜互动画卷上完成的内容深化版本。保留 12 个场景、拖动缩放、原有九段小流程、既有插画和《老街》伴奏；增加人物关系、跨场景事件和本地记忆。无构建步骤、无后端、无账号；游玩进度和明信片留言仅保存在本地浏览器。

底部原有的时间、地点、署名信息框已移除，保留可用的区域导览与上一处 / 回全景 / 下一处。

## 运行

项目入口是 `index.html`。解压后保留完整目录。全部脚本、图片、字体与声音均在本地，没有 CDN 依赖。

推荐双击 **打开本地预览.cmd**。电脑有 Node.js 时会打开 http://127.0.0.1:4325/index.html，也可以执行 `node server.mjs`；没有需要安装的项目依赖。服务只监听本机。没有 Node 时启动脚本会直接打开 HTML。

本轮实际浏览器验证使用本地 HTTP。直接双击路径使用普通 script、相对图片和内嵌明信片图片实现，未使用模块或 fetch 读取配置；file:// 未做浏览器实测。进度按浏览器及地址分别保存，请尽量保持同一预览方式。

## 先逛一件小事

1. 晨起到 **早市菜摊**，挑两样菜、称重；选择“替陈姨留这篮”，也可选择自己带走。
2. 入夜到 **巷口煨汤**，与周姐核对实际选中的菜，再确认交接。菜先在菜摊保鲜箱寄存，傍晚交来是备明早的料；今晚那锅汤中午已上火。
3. 到 **街坊纳凉** 找陈姨，她把空篮留在桌边。主动“接过空篮”，事件收尾。

有莲藕时，周姐留作明早的藕汤；没有莲藕时，你带来的是配菜，藕由她另备。没接受帮忙、没去菜场，都不会被算成已交菜，也不影响逛全部场景。交接只发生一次；回访、刷新都有对应回应。

画卷按地点展开，呈现这一天不同钟点的片段，不是一条强制按顺序通关的路线。

## 三位会记事的街坊

- **陈姨**：退休缝纫工，明早替汤铺切菜；总要辨清篮子的主人，也不太相信李伯的“修好能坐十年”。送菜进度、空篮是否取回、你是否认过吴姐的杯，会改变她的回应。
- **李伯**：退休轮渡机修工，收音机刻度差半格也要拧正。看完他的“橡皮圈”节目，再回桌边交谈，会讲到他和陈姨各修一半的习惯；验过船票也有回应。
- **吴姐**：过早铺摊主，口味先写便条再下碗。你实际选择的少辣 / 多葱 / 原味会保留；没选过，不会擅自说“照旧”。她还在找底下刻三角的搪瓷杯。

人物是原创虚构。汤铺的周姐沿用既有摊主画面，是交接这一篮菜的街坊，不新增角色模型。

## 物件与纸张里的线索

旧单上添的“第二锅出锅时间”、灶边口味便条、熟客预留牌、电影预告、杯子招领条、押瓶本、蒲扇背面的名字、修过的凳脚、票背提醒、吴姐杯底的记号，各有具体主人和来历。

纸笺随画卷移动、缩放；展开时会避开阅读区和底部导览。还有人物短对话、世界中的菜篮变化、可展开的小报、时间对照和字幕节目，不把所有内容都做成同款弹窗。

- **小报**：保留纸角展开操作。四则原创内容包括电影预告、杯子招领、备料近况和街坊来信。可读后放回，也可夹好带走；两者在轮渡和明信片里分开记录。
- **字幕广播**：保留旋钮调台，89.4 / 96.8 / 104.2 是作品的虚构调音刻度。三段原创节目各六句，自动约 30 秒；可暂停或逐句阅读。调离、离场或页面隐藏会停止 / 暂停字幕；配乐随之恢复，保留用户设定音量。
- **院坝电影**：拉幕、转手轮、对焦后，播放四段原创插画短片《一只篮子借了三回》，约 28 秒。读过小报、留菜 / 交菜 / 取回空篮会改变叙事。跳过晨起也能理解基础故事。可停在一页读，再继续。
- **时间层**：门框旧单、票背字迹和凳脚修补，对照故事中的 2009 / 2012 年与今天。纸张和修补标记为原创演绎，凳脚使用同一张已有插画局部，不是历史照片或真实史料。
- **明信片**：1600×1320 PNG，由已有全景、你的短句和真实经历合成。所选口味、实际挑菜、交接阶段、是否验票、是否取报、发现的物件、读完的节目等有独立记录。未取得的物件不会进入个人记录。

## 进度、重逛与声音

故事使用 `wuhandong-story-day` 本地存储键，数据版本为 1。安全读取、校验枚举和选菜快照；存储损坏或不可用时仍能在当前会话正常体验。晨夜切换和刷新会保留故事进度，刷新后进入最近时辰的全景。

顶部 **这一天 → 重新逛这一天** 会清除故事进度并重置画卷位置。原有明信片文字 `wuhandong-note` 和本地选择的配乐不清除。

《老街》伴奏仍由首次主动点击后启动，默认 14% 音量。右上角可静音或调音量。字幕播放时配乐降低，结束、暂停、切台、离场恢复到用户设定值；不会自行取消用户静音。

**广播目前是完整可用的文字字幕版，尚无人声配音。** 当前可用工具中没有合适的配音生成功能，未用无关拟音冒充节目。后续可以接入获授权的口述人声、真实个人旧照与回忆；它们不是本轮可用性的前提。

## 主要文件

- `index.html`：入口、简化导览、故事对话与重逛入口。
- `periods.js`：真正生效的晨夜场景、热点与动作配置。
- `content.js`：人物、分支对白、物件来历、小报、节目、电影与个人记录文案。
- `story-state.js`：共享进度、版本校验、事件转换、本地保存与重置。
- `story-ui.js` / `story.css`：人物回应、可展开纸笺、菜篮图层、时间对照与适配。
- `journeys.js`：原小流程与故事状态连接，节目、电影及计时器 / 监听清理。
- `app.js`：镜头、切场、旧动作保护、自动做面和明信片。
- `music.js`：原配乐管理及节目期间音量恢复。
- `scenes.js`：保留的基础记录与食物文案；不主导本版导航。
- `assets/`：原有插画、道具、字体、蒸汽、脚本与音效。本轮无需新外部素材。
- `qa/story-day/`：本轮实际截图、浏览器记录、状态测试与资源检查。旧版截图不作本轮验收。
- `assets-manifest.json`：当前交付文件体积与 SHA256。

实际情况详见 `qa/story-day/验证记录.md`。本轮覆盖含藕 / 无藕 / 不帮忙 / 直接夜游、交付去重、取回与刷新、重逛、人物回访、切台及配乐恢复、快速切场、真实经历明信片，以及桌面和手机阅读。
